# ScholarAI v3 SOTA (sensorspine-humaniser-v3)

ScholarAI v3 is a state-of-the-art text humanizer designed to achieve **Deep Semantic Evasion**. It works by reconstructing text from pure concepts (AMR graphs) and refining the output using **Contrastive Decoding** to penalize AI-predictable token patterns.

## 🚀 Optimized for MacBook M2 (8GB RAM)
This project uses a **Split-Architecture** to overcome local hardware constraints:
- **Backend:** Runs on a free Google Colab (T4 GPU) to handle heavy LLMs (Llama-3 8B, GPT-2).
- **Frontend:** Runs locally on your Mac using Next.js.

---

## 🛠️ Getting Started

### 1. Setup the Backend (Google Colab)
1. Open [Google Colab](https://colab.research.google.com/).
2. Upload `backend/backend_runner.ipynb` and all files in the `backend/` directory to the Colab environment (or push to GitHub and clone).
3. Set the runtime to **T4 GPU** (Runtime > Change runtime type > T4 GPU).
4. Run the **Setup** cell to install dependencies and download models.
5. Run the **Run** cell. It will ask for an `ngrok` auth token.
   - Get a free token from [ngrok.com](https://ngrok.com/).
6. Copy the **Backend API URL** (e.g., `https://xxxx.ngrok-free.app`) generated by the notebook.

### 2. Setup the Frontend (Local Mac)
1. Open your terminal in the `frontend/` directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Usage
1. Paste the **Backend API URL** from Colab into the dashboard's "Backend URL" field.
2. Paste your AI-generated text.
3. Adjust the **Intensity** slider (higher = stronger evasion).
4. Click **Execute Semantic Evasion**.

---

## 🧠 Core Technologies
- **AMR (Abstract Meaning Representation):** Strips syntactic bias.
- **Contrastive Decoding:** Penalizes $P(AI\_token)$ to force human-like linguistic choices.
- **Recursive Judge:** Self-evaluates perplexity and regenerates if output is too predictable.

## 🔒 Security Note
Never share your `ngrok` auth token. The backend is exposed via a public tunnel, so ensure you only run it when needed.
